Hello this is Cameron, I'm in the process of creating a fun visual learning site about the Paleozoic era. I used studio code and AI for my layouts, images, and videos. This site was create for an ITD 210 project.

Capstone 1 - Home page. Added 6 cards that included AI generated videos for each of the 6 periods. Added a hero with buttons that redirect user to the gallery page or the timeline page for my info. Cards also redirect users to the timeline and use JS to control the looping of the videos. I fixed the corners of the videos and cards and made them more rounded and presentable.

Capstone 2 - Contact Page. I created a contact page that included a picture of myself and a short description about why the website was created. Later added JS joke section for using API Fetch. I also added an animation that reveals words and images/videos as you scroll down the home page.

Capstone 3 - Gallery page. Added gallery page with images and cards. Used caption and descriptions on images, and added a credit section. Fixed about page using Tailwind styles instead. Fixed index page white gap at the bottom of the page.

Capstone 4 - Media page. Added Canva imported video and embedded youtube videos. Used captions, transcript, and original audio. Add credit to the sites used to create the video. Fixed layout that include videos in descending order. 

Capstone 5 - Contact & Timeline page. I added a formspree section on as the official way to contact me. I also add a checkmark feature and a hero to match the rest of my pages. The timeline is the bonus page, that contains most of the in-depth information of each of the periods. Showcasing a circular globe with photos, references, and a description for each. I fixed the mobile nav so that the cards are visible and readable for the timeline and the side bar navigation so it matches all the rest of the pages. I applied reval and scroll animation to all pages of my site.

Project reflection - What is the strongest part of your final site and why?
 The strongest part of my site is my timeline page. The timeline page contains the most educational information, which is why I decided to built this site to began with. It contains an interactive timeline, images that use light-box and descriptions of what each period climate, life, and overall change and impacts it made.

What did you learn about responsive design and interactivity this semester?
 I learn how to use Java script to add interactivity and how animations can improve the overall user experience of a website. I also learned how responsive design helps a site adapt to different screen sizes, making it more usable and visually consistent on mobile, tablet, and desktop devices.

Which piece of feedback changed your approach the most? 
The most impactful feedback was making my home page more rounded and welcoming. I learned that the home page is the first impression of a site, so it needs to quickly attract attention. I improved my layout, spacing, and visual design to make it more engaging and easier to navigate.
